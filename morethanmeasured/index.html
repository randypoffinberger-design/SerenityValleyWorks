iPhone or iPad · Safari

  1. Open the live app in Safari.
  2. Tap Share. If needed, tap the Page Menu first, then Share.
  3. Tap Add to Home Screen, turn on Open as Web App if shown, then tap Add.

Android · Chrome

  1. Open the live app in Chrome.
  2. Tap the three-dot menu and choose Install app or Install and create shortcut.
  3. Tap Install and follow the prompts.
